## Find Your Workflow

### Encrypt data

Start with [AegisCipher](/api-reference/aegiscipher/) and [KeyPair](/api-reference/keypair/).
Choose a [security level](/api-reference/security-levels/) and inspect the
[exception hierarchy](/api-reference/exceptions/). [MlKem](/api-reference/mlkem/)
exposes raw KEM operations for advanced protocols.

### Work with files and asyncio

[Streaming](/api-reference/streaming/) processes data in chunks; memory use
depends on input chunking. [Async methods](/api-reference/async-methods/) offload
encryption and decryption to a thread pool; key generation stays synchronous.
[Key serialization](/api-reference/key-serialization/) covers PEM, JSON, and
encrypted persistence with high-entropy wrapping secrets.

### Understand key lifetimes and security

[Ephemeral sessions](/api-reference/ephemeral-session/) and the
[context manager](/api-reference/context-manager/) provide lifecycle helpers,
not complete erasure or forward-secrecy guarantees. Selected Rust buffers are
zeroized; caller-owned Python bytes and all key copies are not covered.

Read the [architecture](/internals/architecture/),
[hybrid KEM-DEM flow](/internals/hybrid-kem-dem/), and
[mathematical foundation](/internals/mathematical-foundation/) for implementation
details. Native operations release the GIL with `py.detach()`. The PEP 561 marker
and native stubs support tooling, but streaming bindings are not yet included
in the stub.

NIST vector tests cover KeyGen and encapsulation outputs; this is not official
ACVP validation. The [FIPS 203 reference](/reference/fips203-compliance/) and
[glossary](/reference/glossary/) explain the standard and terminology. Timing
defenses are not a complete side-channel audit.
