## Why AegisQ?

AegisQ is a hybrid cryptographic library that combines **ML-KEM** (FIPS 203) for quantum-resistant key encapsulation with **AES-256-GCM** for authenticated symmetric encryption. The cryptographic core is written in Rust for performance and security guarantees, exposed to Python via PyO3.

<CardGrid>
  <Card title="Quantum-Safe" icon="shield">
    ML-KEM (FIPS 203), resistant to Shor's algorithm. Your data stays secure even against future quantum computers.
  </Card>
  <Card title="Constant-Time" icon="approve-check-circle">
    `subtle::ConstantTimeEq` with no secret-dependent branches. Immune to timing side-channel attacks.
  </Card>
  <Card title="Memory Zeroization" icon="warning">
    `zeroize::Zeroize` on all structures containing secrets. Keys are securely erased after use.
  </Card>
  <Card title="Rust Core, Python API" icon="rocket">
    Rust performance with Python ergonomics. Encrypt data securely in just 3 lines of code.
  </Card>
  <Card title="GIL Release" icon="forward-slash">
    `py.detach()` for true parallelism during crypto operations. No GIL bottleneck.
  </Card>
  <Card title="Type-Safe" icon="document">
    PEP 561 type stubs with full IDE autocompletion support. Catch errors before runtime.
  </Card>
</CardGrid>

## Beyond the Basics

AegisQ ships production-ready extensions on top of the one-shot hybrid flow:

<CardGrid>
  <Card title="Streaming Encryption" icon="stream">
    Encrypt gigabyte-scale files with bounded memory via `encrypt_stream` / `decrypt_stream` generators. v1.5.0.
  </Card>
  <Card title="Async API" icon="rocket">
    `encrypt_async` / `decrypt_async` offload to a thread pool without blocking the event loop. v1.4.0.
  </Card>
  <Card title="Key Serialization" icon="document">
    PEM, JSON, and encrypted-PEM persistence with HKDF-SHA3-256 password protection. v1.3.0.
  </Card>
  <Card title="Forward Secrecy" icon="seti:forward">
    `EphemeralSession` auto-destroys each ephemeral keypair on close — past sessions stay safe.
  </Card>
  <Card title="Context Manager" icon="seti:config">
    `with AegisCipher()` proactively zeroes any registered Python-side buffer on exit. v1.4.0.
  </Card>
  <Card title="NIST KAT Verified" icon="approve-check-circle">
    Implementation validated against NIST ACVP test vectors — bit-exact match with the reference implementation.
  </Card>
</CardGrid>
