## From PyPI (Recommended)

AegisQ is published on [PyPI](https://pypi.org/project/aegisq-pqc/) with pre-built wheels:

<Tabs syncKey="installation">
  <TabItem label="uv">
```bash
uv add aegisq-pqc
```
  </TabItem>
  <TabItem label="pip">
```bash
pip install aegisq-pqc
```
  </TabItem>
</Tabs>

**Requirements:**
- Python ≥ 3.11
- No Rust toolchain needed when a wheel is available for your platform; otherwise installation builds from source

AegisQ targets PyO3's **abi3-py311 stable ABI**. Wheels are still OS/architecture-specific; ABI compatibility does not establish testing on every future Python version or free-threaded build.

## From Source (requires Rust toolchain)

If you want to build from source (e.g., for development or auditing), follow either workflow below. `uv sync --dev` may refresh `uv.lock` to match the checkout; `--locked` is only appropriate when the lockfile is already synchronized with the project version and dependencies.


<Tabs syncKey="installation">
<TabItem label="uv">
```bash
# Clone and build
git clone https://github.com/AC-Santiago/AegisQ.git
cd AegisQ

uv sync --dev

uv run maturin develop --release
```
</TabItem>
<TabItem label="pip">
```bash
# Clone and build
git clone https://github.com/AC-Santiago/AegisQ.git
cd AegisQ

python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install maturin

maturin develop --release
```
</TabItem>

</Tabs>



### Development Build (debug, faster compilation)

For development and testing, you can use a debug build which compiles faster:

```bash
uv run maturin develop
```

## System Requirements

| Requirement | Version |
|-------------|---------|
| Python | ≥ 3.11 |
| Rust (source build only) | Latest stable via [rustup](https://rustup.rs/) |
| OS | Linux, macOS, Windows |

:::note
AegisQ's native extension targets the Python Stable ABI with `abi3-py311`. With the pip workflow, run `maturin develop` inside the activated virtual environment instead of `uv run maturin develop`. Source builds use the version declared by the checkout, which may be a prerelease.
:::
