## Desde PyPI (Recomendado)

AegisQ está publicado en [PyPI](https://pypi.org/project/aegisq-pqc/) con wheels precompilados:

<Tabs syncKey="installation">
  <TabItem label="uv">
```bash
uv add aegisq-pqc
```
  </TabItem>
  <TabItem label="pip">
```bash
pip install aegisq-pqc
```
  </TabItem>
</Tabs>

**Requisitos:**
- Python ≥ 3.11
- No requiere Rust si existe un wheel para su plataforma; en caso contrario se compila desde el código fuente

AegisQ usa el **ABI estable abi3-py311** de PyO3. Los wheels siguen siendo específicos de SO/arquitectura; la compatibilidad ABI no demuestra que cada versión futura de Python o build free-threaded haya sido probada.

## Desde el Código Fuente (requiere toolchain de Rust)

Para compilar desde el código fuente (por ejemplo, para desarrollo o auditoría), use uno de estos flujos. `uv sync --dev` puede actualizar `uv.lock` para coincidir con el checkout; `--locked` solo corresponde si el lockfile está sincronizado con la versión y las dependencias del proyecto.


<Tabs syncKey="installation">
<TabItem label="uv">
```bash
# Clonar y compilar
git clone https://github.com/AC-Santiago/AegisQ.git
cd AegisQ

uv sync --dev

uv run maturin develop --release
```
</TabItem>
<TabItem label="pip">
```bash
# Clonar y compilar
git clone https://github.com/AC-Santiago/AegisQ.git
cd AegisQ

python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install maturin

maturin develop --release
```
</TabItem>

</Tabs>



### Build de Desarrollo (debug, compilación más rápida)

Para desarrollo y testing, podés usar un build debug que compila más rápido:

```bash
uv run maturin develop
```

## Requisitos del Sistema

| Requisito | Versión |
|-----------|---------|
| Python | ≥ 3.11 |
| Rust (solo build desde fuente) | Última versión stable vía [rustup](https://rustup.rs/) |
| SO | Linux, macOS, Windows |

:::note
La extensión apunta al ABI estable de Python con `abi3-py311`. En el flujo pip, ejecute `maturin develop` dentro del entorno virtual activado, en lugar de `uv run maturin develop`. Los builds desde fuente usan la versión del checkout, que puede ser una prerelease.
:::
