## ¿Por qué AegisQ?

AegisQ es una biblioteca criptográfica híbrida que combina **ML-KEM** (FIPS 203) para encapsulación de claves resistente a computadoras cuánticas con **AES-256-GCM** para cifrado simétrico autenticado. El núcleo criptográfico está escrito en Rust para garantizar performance y seguridad, y se expone a Python vía PyO3.

## Más Allá de lo Básico

AegisQ incluye extensiones listas para producción además del flujo híbrido one-shot:

<CardGrid>
  <Card title="Cifrado en Streaming" icon="stream">
    Cifrá archivos de gigabytes con memoria acotada usando los generadores `encrypt_stream` / `decrypt_stream`. v1.5.0.
  </Card>
  <Card title="API Asíncrona" icon="rocket">
    `encrypt_async` / `decrypt_async` descargan el trabajo a un thread pool sin bloquear el event loop. v1.4.0.
  </Card>
  <Card title="Serialización de Claves" icon="document">
    Persistencia en PEM, JSON y PEM cifrado, con protección por contraseña vía HKDF-SHA3-256. v1.3.0.
  </Card>
  <Card title="Forward Secrecy" icon="seti:forward">
    `EphemeralSession` destruye automáticamente cada keypair efímero al cerrar — las sesiones pasadas quedan a salvo.
  </Card>
  <Card title="Context Manager" icon="seti:config">
    `with AegisCipher()` zeroiza proactivamente cualquier buffer Python-side registrado al salir del bloque. v1.4.0.
  </Card>
  <Card title="Verificado con KAT de NIST" icon="approve-check-circle">
    Implementación validada contra los vectores de prueba NIST ACVP — coincidencia bit-a-bit con la implementación de referencia.
  </Card>
</CardGrid>
